# projectList
List of all my github projects


## Qt programs

[VDV301tester](https://github.com/frutabruta/VDV301tester/tree/dev)
Simulator of VDV301 OBU

[VDV301display](https://github.com/frutabruta/VDV301display/tree/dev)
Simulator of VDV301 Passenger LCD display

[Vdv301ApcTester](https://github.com/frutabruta/Vdv301ApcTester)
Program to test communication with VDV301 APC sensors - PassengerCountingService

[LogGpxMerger](https://github.com/frutabruta/LogGpxMerger)
Tool to add GNSS location from GPX file to message log from VDV301display

[QtLocationRelayVdvGnss](https://github.com/frutabruta/QtLocationRelayVdvGnss)
Tool to send GNSS location from serial port of Windows location API to VDV301tester

[GolemioLocationGetter](https://github.com/frutabruta/GolemioLocationGetter)
Tool to send GNSS location of a vehicle from GolemioAPI to VDV301tester

[GolemioTransferBoardsTester](https://github.com/frutabruta/GolemioTransferBoardsTester)
Tool to download and record GolemioAPI departures from TransferBoards endpoint

[IBISparser](https://github.com/frutabruta/IBISparser)
Program to decode a binary serial port log to VD300 (IBIS) commands represented as HTML data

[Hex2BinaryTextConvertor](https://github.com/frutabruta/Hex2BinaryTextConvertor)
Program to convert HEX log to ASCII characters


[Qt6EscPosSerial](https://github.com/frutabruta/Qt6EscPosSerial)
Example of controlling a ESC/POS printer from Qt

[PhotoFolderSorter](https://github.com/frutabruta/PhotoFolderSorter)
A tool to sort photos to 5 selected folders by pressing hotkeys (F1-F15)
